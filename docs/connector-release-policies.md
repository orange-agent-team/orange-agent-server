# G3 连接器发行与授权兼容

服务端的 [G3 发行清单](../config/connector-releases.v1.json) 固定六个适配器的上游 API、契约文件摘要、资源范围与 26 个只读动作。每个动作单独记录执行摘要，输入及输出引用按本地 JSON Schema 展开后参与计算。读取源状态、生成外部文件引用和写入本地隔离区是不同的本地效果。

每次签发 Run 授权时，数据库在同一事务内记录其发行版本。升级前已经存在的授权被绑定到原有只读动作集，已撤销记录保留。动作表从不可变发行记录内的完整动作映射展开。发布新版时可以追加新的发行记录，不能给旧记录追加写动作，已有授权也不能改绑到新版。服务端在源端读取、模型派发和附件下载前，对照原授权中的动作摘要和当前实现的必需摘要。

兼容的动作可以沿用动作摘要。变更输入语义、权限边界、输出类型或本地副作用时应分配新摘要。新增权限需要显式的新授权路径。版本绑定之外，每次访问还要检查会话、Run、资源白名单、撤销和来源健康状态。

```sh
python3 scripts/check-connector-releases.py
python3 scripts/check-notion.py --database-url-file .local/database-url --identity-config .local/identity/user-config.json
```

第一项核对当前六个配置与契约、动作摘要和不可变迁移种子。第二项使用旧结构已存在的授权与回执，升级后检查旧授权可读的动作，验证新发行记录无法扩张旧授权。厂商账号与 API 实测单独取证。发行清单列出的能力不代表所有租户已经通过认证。
