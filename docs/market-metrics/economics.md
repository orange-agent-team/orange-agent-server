# 现金、积分及成本口径

PRD-006.02。对每个原币种独立统计最小货币单位；积分字段统一为整数微积分。报表为运营分析，经营主体的正式财务入账口径需另行确认。

| 来源 | 处理 |
|---|---|
| 购买与退款 | 确认购买按原币种和原订单归集。只按成功退款回执减少现金；部分退款的积分数量沿用原购买比例的累计向上取整差额 |
| 拒付与恢复 | 拒付引用原购买，追回引用原争议。净现金流为购买减退款、减拒付、加追回。仍有争议余额的币种暂不计算贡献毛利 |
| 消费积分 | 结算额等于赠送、贡献、购买三个分桶消耗之和，也等于供应者待入账加平台积分费。预留与释放不构成当期消费 |
| 现金支持的已交付服务额 | 按购买批次归属，计算“累计已消耗单位 × 原购买金额 / 原购买单位”的向下取整差额。逐次累加保留原币种。无法归属的历史购买积分单列 |
| 供应者收益 | job_settlements 的 provider_pending 是新入待审核桶的金额。provider_earning_releases 的独立释放回执产生当期可消费收益；未知释放历史用 null 表示。贡献积分消费不能再次确认现金 |
| 变动成本 | 分别归集供应激励履约成本、平台计算、失败重试补贴、存储、出口带宽及渠道处理费用。成本凭据按一个分类记一次。供应商现金成本按实测或明确标注的情景输入，不由积分汇率猜测 |
| 平台贡献毛利 | 同币种归属服务额减完整变动成本。成本覆盖不完整、购买积分缺原批次或存在未处理拒付时，结果留空；已知成本仍可查看。毛利率另列精确分子和分母，服务额为零时留空 |

成本样例包含促销作业及失败尝试的开销。未观测的存储与带宽成本在真实数据回归中保留 null；显式确认该窗口某项成本为零后才视为完整。单位任务成本按该币种的完整变动成本除本期结算任务数，包含为这些业务承担的失败成本。不同币种之间不隐式换算。
