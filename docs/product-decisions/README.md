# 实施决策与上线依赖

本目录对应 PRD-005。范围基准来自已批准的四仓实施计划。历史研究中的架构候选仍可用于比较。当前 Agent 路线已选定为自有 Rust 宿主与执行控制层，推理引擎另行适配。

| 登记材料 | 用途 |
|---|---|
| [决策登记表](register.json) | 保留每个事实的来源、分类和具体待验证项 |
| [架构决策索引](architecture.md) | 追踪控制面、注册、积分和引擎的原因及影响 |
| [上线依赖](launch-dependencies.json) | 记录经营、基础设施、硬件和发布资格所需的实际凭据 |
| [变更与重新验收](changes.md) | 找到需同步的契约、架构图、下游仓库与验收任务 |

“用户确认”只覆盖原答复的粒度。约 10 人是投入能力；岗位已到岗需排班证明。地区名称是部署目标；经营主体、具体首发地和在地实际服务仍待落实。单台设备的报告不提供目标驱动或多卡验证凭据。开发账本费率可以复算，但商业费率仍待经营确认。
