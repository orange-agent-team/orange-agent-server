## 投影规则

1. 先取得完整合法响应，检查选定工具schema和响应提交资格。E04返回的候选本身不能授权工具或扣费；目前完整schema/提交/结算服务链路仍待接通。
2. 所有可见自然语言文本按原顺序拼成一个text分量，保留Unicode与空白，不逐chunk分词相加。
3. 工具调用按逻辑索引顺序各产生两个分量：实际模型可见tool_name，以及完整arguments的JCS JSON。参数键序/无意义JSON空白、1与1.0、负零按RFC8785规范化；参数字符串本身不做Unicode正规化。
4. 每个完整分量使用固定tokenizer分别分词后求和。分量之间不插入收费分隔符；分量标签、数组包装、call_id、response_id、宿主注入字段、协议封装、隐藏推理及EOS不收费。参数JSON自身的标点属于用户可查看的规范参数表达。
5. profile及参数规范化/别名映射版本必须进入请求投影与Quote，不能靠升级网关偷偷改变计量。工具名在平台内部别名转换前固定；改名或改schema需要新投影/报价。

实现采用固定 `serde_jcs 0.2.0`，许可MIT或Apache-2.0，Cargo.lock固定校验值；serde_json启用float_roundtrip。Orange的前置限制比完整I-JSON更窄：所有数值必须有限且绝对值不超过9007199254740991，超过范围的精确值必须按工具schema用字符串表示，不静默转换；重复键、孤立代理码点、非法/截断JSON和非对象参数拒绝。参数/文本及总规范分量有1 MiB边界，一次最多80个工具调用。未来扩展需要新profile，不能改变v1含义。

## 完成、取消与上限

| 已验证的交付事实 | 规则 |
|---|---|
| 完整胜出成功 | 固定输入单位＋所有规范输出分量；自然空回复可以只收输入 |
| 用户取消且仅有已持久化可取的合法文本 | 输出单位大于0才收输入＋该前缀；没有可取输出则0 |
| 含工具响应尚未提交、参数截断或schema非法 | 不执行工具；该次费用0。无法计量的部分保持未知，不能把未知usage伪造为测得0 |
| 平台失败/超时、旧失败或被替换的attempt | 0；只对最终有效胜出attempt计算一次 |
| 完整响应超过规范输出上限 | 拒绝；不截断参数、不追加超报价费用 |

原生生成token上限与规范分量token上限是两道独立检查。现有E04只完成原生上限和候选完整性检查；规范上限计算库已有实现，尚需在实际网关提交前接入。Quote的最大费用由固定输入、规范输出上限及整数单价计算；计价函数只做纯计算，不建立交付事实、不扣款、不结算Job。

## 实际固定样例

样例文件是 `contracts/fixtures/metering-v1.json`，包含输入/输出字节、每个分量完整token IDs、单位、上限、费用与分成。词表来自固定llama.cpp提交中的Qwen2词表，SHA-256为 `44c2f46b715f585c6ab513970e8a006bfa5badd6108560054921cf598d154d8c`。测试输入是明确的模板夹具，其特殊token模式下实际计26个token；它不是经完整模型验证的生产chat template。

以下是算术夹具，使用原X-BILL假定云单价：输入2000、输出6000微积分/千token，费率2000bps，输出上限128，Quote最大820微积分。实际测试没有产生平台收费；LocalOnly执行仍须使用零平台单价。

| 样例 | 实际规范输出token | 费用夹具（微积分） |
|---|---:|---:|
| 普通文本 | 3 | 70 |
| 纯工具调用 | 14 | 136 |
| 文本＋两个工具 | 31 | 238 |
| 等价分片/参数键序 | 31 | 238 |
| 参数截断 | 未知／投影拒绝 | 0，因未提交而非猜测usage |
| 取消且持久化文本 | 3 | 70 |
| 重试胜出 | 3 | 70，旧attempt为0 |

验证命令：先按 `prepare-local-model.py build --source-checkout <固定参考库> --target llama-tokenize` 编译词表工具，再运行 `python3 scripts/check-metering.py`。检查脚本核对源码提交、二进制/词表摘要，实际调用原生分词工具，并独立核算整数金额；不会自动重写golden。另验证输出中可见的特殊token字样按普通文本计量，以及无效工具取消标签、超限、空取消和协议ID变化的边界。

当前证据不能证明该独立词表与尚未下载成功的完整Qwen GGUF完全相同，也不能替代MC/MP实际输出、取消/失败竞争和恢复验证。DR-01剩余准入项：绑定生产ModelVersion/tokenizer/template/profile、Quote数据库字段和预算上限、实际网关规范化、已提交交付/原始usage证据、用户授权明细，以及MP-01/02等支持组合逐项对照。条件满足前收费功能保持关闭。

规范依据：[RFC8785](https://www.rfc-editor.org/rfc/rfc8785.html)、[serde_jcs 0.2.0](https://docs.rs/serde_jcs/0.2.0/serde_jcs/)、[固定词表工具源码](https://github.com/ggml-org/llama.cpp/blob/b74298c109c107494b792c30af4bb8fa0ce1eb2f/tools/tokenize/tokenize.cpp)。
