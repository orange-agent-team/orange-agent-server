# Worker 控制协议 v1

[传输定义](../../contracts/proto/worker.proto)由固定版本的 protoc 生成。控制连接必须通过 TLS 双向认证，网关再核对证书指纹、设备登记、账户与当前授权。受同一测试 CA 信任但尚未登记的证书不能领取作业。握手先交换 Hello 和 Welcome，再创建后续控制消息的权限上下文。

| 能力 | 声明和依赖 | 既有调用方 |
|---|---|---|
| 控制、执行 | 协议主版本 1，节点控制与执行版本各为 0、1、2。2 支持保守的本地执行预算与当前策略代次。 | 仅握手和心跳的客户端保留 0；执行能力为 0 时无分配。 |
| 拒绝回执、输入、CPU 清理 | 每项为 0 或 1；启用时要求节点与执行均为 2。 | 缺少能力的客户端不能继承已协商能力。 |
| 续租、输出 | 续租要求版本化输入能力，输出要求续租和输入。网关还须配置相应的真实对象读取器或写入器。 | 旧客户端不能使用可选 RPC。 |
| 转写输入、输出 | 转写输入要求版本化输入；转写输出同时要求转写输入和输出能力。 | 注册转写观察、模型版本和资源授权另行核对。 |

共享类型 ControlVersions 用于 Worker 发起连接、验证 Welcome、服务端握手和会话持久化。v1 范围内的 1152 种声明有 40 种合法组合。未知版本被拒绝，错误组合不能替换原会话、重置连接 epoch 或创造一次启动。能力摘要描述设备申报，执行权限仍需当前 mTLS 身份、审核型号、租约和权威记录。

| 边界 | 持久或可校验的事实 | 不确定时的行为 |
|---|---|---|
| 报价与冻结 | 业务所有者、原预算、固定模型/请求摘要、幂等键及原积分桶 | 查询原命令，不因客户端重发而增加冻结 |
| 分配 | 同一 Job、Attempt、Node、会话 epoch、租约 ID、fencing token、策略代次、截止时间及不可变命令摘要 | 重连不能把旧分配变成新的有效尝试 |
| 接受与开工 | 设备先持久化本地意图并保留资源；accepted ACK 经服务端核对后记录，再返回 StartGrant | 仅收到 Assignment 或发出 ACK 均不能开始执行。丢失回复时仅能取回同一授权事实 |
| 输出流 | 请求头绑定已接受 ACK、租约、对象长度、SHA-256、响应摘要。每块按严格字节偏移排序，完整提交才发布；非流命令按其唯一 ID 和摘要去重 | 偏移错误、旧连接、替换输入或不完整传输不得发布。结果和账本结算分别验收 |
| 续租和停止 | 心跳只续控制会话。执行续租用原请求身份与本地单调时钟锚点，受 Job 截止时间限制；丢失确认不能从当前时间重算授权 | 续租中断时结束本机监督的进程，保留不确定的云端事实。在资源回收确认前不能复用或宣称成功 |
| 流控 | 单控制流的发送队列限制为 8 帧，写入超时关闭流；数据库操作和首次 Hello 都有时限 | 慢接收方不能无限占用网关发送队列；断线不构成取消、完成或退款 |

在服务端依次运行 `python3.12 scripts/check-worker-contract.py --section handshake`、execution、renewal、roundtrip。测试使用专属 PostgreSQL、临时 CA 和临时对象。renewal 还会启动本机已有的固定 CPU 模型，让真实续租权威暂时不可达，再验证子进程清理、无结果发布与账本保留。其他任务往返采用显式固定输出，GPU 驱动与生产设备资格另行验收。

## 最低版本的线格式

最低样本取自服务端提交 `5849d9678ffa701540964aa0333f9d7309373f27`，该提交包含通过 mTLS 建立控制会话的 Worker 客户端。样本同时固定了原始 schema 的 SHA-256、textproto 和实际十六进制编码。[样本与来源](../../contracts/fixtures/worker-v1-baseline/vectors.json)

| 输入 | 当前接收方的行为 |
|---|---|
| 初代 v1 Hello，未声明执行能力 | 可申请控制会话，执行能力取零；是否建立会话仍由设备身份与授权决定。 |
| 新 v1 Hello 或 Welcome | 最低版本读者可还原原字段，新读者还能读取新增能力。连接代次在超过 JavaScript 精确整数范围时仍保留原值。 |
| 未支持的主版本 | 已登记的设备收到 gRPC FAILED_PRECONDITION，当前会话保持有效。 |
| 仅声明续约，缺少所需输入能力 | 已登记的设备收到 gRPC INVALID_ARGUMENT，原会话可继续心跳。 |

`python3 scripts/check-worker-wire-vectors.py` 对照两个 schema 编码并解码固定字节。`cargo test --locked --offline -p orange-protocol --features grpc --test worker_wire_vectors` 使用实际 Rust 生成类型，`python3 scripts/check-worker-contract.py --section handshake` 使用独立开发数据库和双向 TLS 测试拒绝原因及原会话状态。

## 运行中撤销凭据

凭据已兑换且作业已获得 StartGrant 时，所有者仍可撤销原注册授权。服务端记录原授权请求编号和撤销时间，并在同一数据库事务中停用关联叶证书。持有旧 TLS 通道的设备重发已提交的续租请求、提交下一序号的续租或再次轮询工作时，网关重新检查当前权限。既有 StartGrant 的截止时间和已记录的续租不因这些请求延长。

用 `python3.12 scripts/check-device-issuer.py --fence-live-work` 验证。验收使用真实注册授权、签发、设备私钥、用户撤销接口、mTLS、PostgreSQL、SQLite 和用户态 Broker。买方预算、报价、受审计算力能力与输入是本地测试数据，使用开发积分。测试先建立成功续租作为对照，再检查原授权撤销后的重放、跨节点密钥副本、独立连接及授权事件计数。真机执行和生产私钥保管另有验收。
