# 业务资源归属与访问主体

本页交付 PRD-001.01 的主体与资源表。账户可以同时购买推理和提供设备。订单、收入、水位与权限分别按资源的业务所有者查询。[机器可读目录](subjects-and-resources.json)

| 主体 | 如何识别 | 可以代表谁 |
|---|---|---|
| 个人用户 | 用户会话中的主体，经当前用户和账户状态检查 | 个人账户；有效成员关系和当前授权所允许的组织 |
| 组织 | 组织编号对应一个账户，用户通过成员关系发起请求 | 组织账户。成员、创建者、原提交人的身份仍可分别记录 |
| 提供方设备 | 当前设备证书、节点登记、会话代次和执行租约 | 仅该节点及本次分配允许的执行；收益进入报价中确定的提供方账户 |
| 平台操作员 | 独立的 Admin 身份、会话、MFA、操作权限、环境和范围 | 授权范围内的平台治理操作，草稿或动作记录保留具体操作人 |

| 资源 | 唯一业务所有者 | 容易混淆的其他关系 |
|---|---|---|
| 任务、报价、预算 | 各自记录中的消费账户 | 报价指定的提供方、原始提交人和支付来源均另存 |
| 音频、输入及结果产物 | 产物记录中的个人或组织账户 | 提供方只可在授权与租约存续期间读取指定输入。结果回执归属于原任务；结果内容读取还检查源和结果权限 |
| 钱包、账本交易、对账事项 | 每条记录明确关联的账户 | 钱包中的赠送、购买、劳动所得、冻结和待入账分别记账。账本分录可以涉及其他账户 |
| 算力节点、设备凭据 | 节点登记的提供方账户；凭据沿节点查询其归属 | 登记用户、节点编号、证书和物理设备分别识别。已成交订单保存当时的提供方 |
| 已审核模型执行配置 | 平台模型目录 | 配置由模型版本、权重摘要和执行配置摘要识别。节点观测、安装缓存和设备持有的权重副本不会使提供方取得目录发布权限 |
| 团队内容、云 Run、隔离工作区 | 内容所属组织，或云记录中的消费账户 | 成员通过资源 ACL 和操作授权访问；云 Host 是执行方 |
| 本地文件与桌面工作区 | 桌面当前操作系统账户所选择的本地工作区 | 工作区许可与远程账户会话分别生效，远程传输需要对应的用户操作和服务端授权 |

数据库验收读取已经迁移的 PostgreSQL 系统目录，验证每条账户归属路径的非空外键、目标列及终点；平台模型注册项还检查了全局配置主键和审核摘要约束。桌面文件表述为本地操作系统边界，由桌面授权、文件打开和隔离路径的专项验收覆盖。
