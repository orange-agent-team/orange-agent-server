ArtifactSpec来自受信配置/审核注册信息，固定HTTPS URL、精确主机集合、大小、SHA-256与文件magic。源URL和每次重定向均检查HTTPS、443、无userinfo/fragment及精确主机匹配；最多5次重定向。禁用Referer和自动压缩，不记录签名URL。下载CLI仅消费固定Hugging Face提交，当前允许主机为huggingface.co和经官方HEAD重定向实际观察到的us.aws.cdn.hf.co；没有镜像或浮动版本回退。

缓存路径由应用配置，不接受模型生成路径。文件以摘要命名，Unix要求私有目录0700，文件0600、禁止符号链接跟随和多硬链接；Windows代码使用reparse-point打开/检查，但目标Windows实测尚未完成，不能当作已经验证其ACL与文件系统行为。

有效缓存命中仍复核大小、magic和SHA-256。新下载保存为.part，保留中断前缀；206必须精确匹配偏移、末尾和总大小。200表示完整响应时从零重建，不把重复完整文件追加到旧前缀。超长数据在写入前拒绝，最终大小和摘要均匹配后同步文件并原子改名。未知/损坏文件不作为模型ready。

每个缓存根使用真实文件锁串行预留下载配额；不删除已有模型，超配额明确拒绝。已验证的只读缓存可在其他下载期间使用。单次最多3次有界尝试，暂时中断保留前缀；损坏前缀只在自身staging文件中重建，不覆盖正在使用的正式模型。阻塞文件I/O同时持有缓存锁的Arc，异步调用者被取消也不会提前释放锁，让另一下载者与旧写入重叠。

`prepare-local-model.py download`现委托Rust/rustls的model-fetch；原Python/LibreSSL下载路径已移除。CLI的4GiB配额仅是当前本机集成配置，库接受调用方明确给出的配额。缓存完整性证明不等于模型审核、授权、收费或运行兼容性。

## 本地文件导入

`import_file` / `import_file_with_cancel` 使用同一固定ArtifactSpec，只读打开用户明确选择的普通文件，不访问网络、不创建源文件的链接。实际字节复制到私有`.import`暂存文件；大小、magic、摘要和暂存文件复读验证通过后才原子发布。源文件后来变化不会改变已安装模型。

导入与下载共用真实缓存锁和配额；暂存导入也计入占用。取消或取消权限通道丢失会拒绝发布；已经完成原子发布时应核对返回/缓存状态，不能把随后收到的取消请求当作删除已验证模型。异步调用者丢弃期间，实际阻塞写入继续持有同一缓存锁。源文件必须在缓存命名空间之外，防止将暂存文件选为源后被截断；符号链接、多硬链接、目录和FIFO均拒绝，Unix非阻塞打开避免等待FIFO。

当前下载CLI也支持显式选择官方ModelScope的固定提交和已验证CDN，仍要求与原始描述符完全相同的大小和摘要；没有自动切换未知镜像。

## 验证与历史网络阻塞

`scripts/check-model-cache.py`执行14项测试，过滤整个`cache::`模块，包括新增`cache::import::tests`。覆盖实际文件复制、源变化独立性、暂存源不被截断、坏文件/配额/锁/取消拒绝、非普通源以及原有恢复、Range和传输故障。传输故障是明确替身，文件系统操作真实；它不是完整模型推理证据。

剩余范围：在用版本引用/卸载、自动清理与并行配额预留、注册审核联动、目标OS认证、其他模型/协议恢复和运行认证。没有建立付费资源、公开发布服务或放宽校验。

缓存租约现由实际写入者共享的专用RAII对象持有，最后写入者结束时显式unlock，避免无关dup/fork描述符把已完成的缓存操作锁继续留住；取消时仍由在途写入持有Arc，不能提前解锁。确定性重复描述符回归在旧实现失败、新实现通过，原在途写入取消测试保持不变。此规则只用于缓存写入租约，不改变模型进程故意继承执行租约的隔离规则。一次完整回归中观察到锁暂未释放；40次组合诊断未再触发原具体时序，不把重复描述符复现声称为已证明原调度原因。
