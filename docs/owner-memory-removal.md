# 所有者删除不可访问的记忆

当原文件已撤权或记忆空间已停用时，空间所有者可以按标识清理记录。目录只查询条目标识、版本及启用状态，每页最多 100 条。提交预览需要匹配当前空间修订和条目版本。共享成员的读写授权不包含所有者清理权。

schema29 的 memory_owner_removals 保存请求、目标版本、五分钟期限、摘要及提交状态。所有者按预览摘要确认。删除事务设置墓碑，清空正文，封锁旧来源任务，提升空间修订，并使原修订下待确认的草稿失效。空间的启停状态保持原值。事务失败会一起回滚墓碑、草稿变更、审计和回执。未提交的过期请求或旧修订请求在后续预览时回收。每个空间同时最多保留 128 个当前待确认请求。

提交成功会撤销旧修订的授权并等待真实读取及执行工作释放。丢失回复后可以查询元数据回执确认数据库是否已提交，再用同一摘要重复确认以等待原修订排空。后续重新授权获得的会话不计入这次排空。逻辑删除覆盖当前数据及恢复时的访问控制，备份和物理介质清除另行验证。
