# 会话刷新与签名密钥轮换

用户和 Admin 使用各自的会话、cookie 与权限存储。用户请求在获得会话、用户和所有者行锁之后读取 PostgreSQL 的当前时间。Admin 还需先获得授权行锁，再逐条筛除已经到期的角色授权。只有仍处于空闲期限和绝对期限内的会话才能续期，续期上限为当前时间加十五分钟和原绝对期限两者中的较早者。到期后的请求返回未认证；它不能延长存储的截止时间。

OIDC 配置固定 issuer、client ID、回调和客户端凭据。每个授权码只兑换一次。兑换成功后，服务端从该 issuer 在启动发现时公布的同源 JWKS 地址读取当前公钥，再验证签名、受众、nonce、时效与可选的 access token hash。读取公钥失败时，当前登录返回服务不可用，用户可以重新发起登录。更换签名密钥无需重启应用。变更 issuer、端点或允许的签名算法需重新加载部署配置。Admin 在签发会话时照常验证要求的认证等级，操作审批仍使用独立批准人。

本地验收覆盖真实数据库排队期间的会话与角色到期。签名轮换测试使用回环协议替身与临时 RSA 密钥，包含换钥、退役、读取失败恢复、错误受众、nonce 和到期。真实开发身份登录继续使用单独的 Keycloak 和 Chrome 验收。
