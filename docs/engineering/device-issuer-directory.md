# 设备签发 CA 目录

管理接口 `GET /admin/v1/device-issuers` 显示所选范围内保留的签发记录。开发环境的平台管理员、安全操作员和审计员需要在所选平台或区域范围实际拥有 `device_issuers.read`。查询和成功读取的审计记录在同一 PostgreSQL 事务中完成。若权限在读取过程中到期，响应和审计写入一同回滚。

每行对应一个 CA 证书的 DER SHA-256。单独的公钥 SHA-256 来自开发签发进程对 CA 约束、固定指纹和实际私钥的匹配核验。以前已经签发的 CA 记录仍能查看；签发器尚未核对该 CA 时，公钥列为空。目录不存储私钥、令牌或证书正文。

| 字段 | 含义 |
|---|---|
| retained_certificates | 当前保留、归属本范围的签发记录数 |
| awaiting_exchange | 叶证书有效、授权仍有效并且尚未兑换的记录数 |
| active_credentials | 叶证书与已兑换凭据均有效、授权未撤销且节点未被撤销的记录数。节点可能离线 |
| expiring_within_hour | 上述有效凭据当中，将在一小时内到期的数量 |
| next_expiry_unix | 有效凭据的最近截止时间，同时核对证书期限与服务端凭据期限 |
| last_prepared_unix | 本范围内最近保存的签发时间 |

客户端按所选范围与 CA 摘要读取下一页。每次请求重新读取管理员权限。游标绑定主体、策略版本、权限集合、范围和原位置；它本身不授予读取权。数量随签发、兑换、撤权和时间变化。查询结果用于密钥运维，节点在线、允许执行模型、GPU 回收及生产信任根撤回另有独立判据。
