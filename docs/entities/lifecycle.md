# 业务实体与数据生命周期

[实体目录](catalogue.json)区分存储主键、跨模块引用和授权主体。个人用户可以拥有个人账户并加入组织。组织支出归组织账户，作业读取还要核对提交者身份。设备属于供应者账户；持有设备证书、持有作业 ID、知道模型版本都不能替代当前授权。

| 数据 | 权威位置 | 撤销、删除和保留责任 |
|---|---|---|
| 桌面会话与本地操作 | 用户设备的 SQLite journal | 桌面宿主管理历史与删除；恢复时再次检查源权限。 |
| 云工作区与输入 | 云 Host 租约、控制面的源授权、对象版本及摘要 | Workspace 所有者管理授权。撤回影响后续提供、发布与读取；控制面保留撤权事实。 |
| 作业与执行尝试 | 支付账户持有 Job；平台与设备共同校验当前 Attempt、租约 epoch 和 fencing token | 节点重连或凭据变化不得恢复旧尝试。未知状态必须核实后再决定回收。 |
| 作业事件 | 服务端受控事件流 | 订阅按当前主体和资源重新校验。事件游标用于恢复读取，不授予内容访问权。 |
| 账本与对账 | 业务账户的交易和分录 | 历史分录保持平衡且不可变。冲正、退款有独立交易及业务标识。 |
| 身份与连接器凭据 | 身份服务、控制面会话及受控凭据存储 | 登出和凭据撤销停止访问。财务记录仍以原账户为主体；令牌和连接串不得写入领域样例。 |

同一 ModelVersion 由版本标识与权重摘要共同引用，对应的 execution_profile_id 还绑定执行配置摘要。模型是否可调度取决于平台审核与当前设备资格。已有数据的数字、UUID 与历史 ASCII ID 均使用相同的线格式。
